주요 기능

학생 기능

  • 게임 기반 학습두더지 게임 방식으로 문제를 풀며 즐겁게 학습합니다.
  • 시간 제한 도전30초 내 최대한 많은 문제를 정답 맞히기에 도전합니다.
  • 실시간 피드백정답과 오답을 즉각 확인하며 학습 효과를 높입니다.
  • 간편한 입장입장 코드(예: 6101홍길동)로 쉽게 게임에 참여합니다.

교사 기능

  • 퀴즈 관리새로운 문제 세트를 제작하고 편집할 수 있습니다.
  • 일괄 문항 등록스프레드시트에서 문제를 복사해 대량으로 등록합니다.
  • 학급 관리학급을 등록하고 학생 명렬표를 일괄 등록합니다.
  • 성과 분석학생별 점수, 문항별 정답률 통계를 확인합니다.
  • 데이터 대시보드누적 결과 현황을 한눈에 조회할 수 있습니다.
  • 교사 인증비밀번호로 교사 전용 기능을 보호합니다.
