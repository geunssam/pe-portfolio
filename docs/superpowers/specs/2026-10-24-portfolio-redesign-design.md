# 근쌤 활동 소개 사이트 개편 — 설계 (2026-10-24)

승인된 시안: https://claude.ai/artifact/WNemNEaetgenXmJ38mgzna (C안 「햇살 드는 서재」 2차)
시안 원본 HTML: `.superpowers/brainstorm/67509-1792793891/content/c-v2.html`

## 1. 왜 바꾸나

지금 사이트(`index.html`)는 "체육 웹앱 7개 모음"이다. 근쌤은 앱만 만드는 사람이 아니라 **읽고(북리뷰), 생각하고(AI 7030·니체 교육철학), 쓰거나(브런치), 만드는(체육 웹앱)** 사람이고, 이 정체성은 이미 유튜브 채널아트 「근쌤의 서재 — 읽고, 생각하고, 쓰거나 만듭니다」로 굳어 있다. 사이트를 **근쌤 활동 전체를 소개하는 곳**으로 바꾸고, 서재 아이덴티티와 이어지게 한다.

보는 사람 (근쌤 확인):
- **연수 수강생** — 강의 뒤 QR·링크로 들어옴, 주로 휴대폰. 남아야 할 인상: "나도 할 수 있겠다."
- **협업 제안자** — 노트북으로 훑어보고 연락할지 정함. 남아야 할 인상: "결과물 수준이 진짜다", 그리고 연락할 길이 바로 보임.

## 2. 목표 / 하지 않을 것 / 실패로 보는 것

목표
- 들어오자마자 "누구인지, 무엇을 하는지"가 **직관적으로 딱** 보인다 (근쌤 표현).
- **한 화면에 한 가지 이야기만.** 정보를 많이 넣지 않는다 (근쌤 확인).
- 프로필(손 흔드는 근쌤 캐릭터)이 첫 화면에 있다 (근쌤 확인: 캐릭터 유지).
- 휴대폰에서 먼저 좋아 보이고, 노트북에서도 어색하지 않다.

하지 않을 것
- 앱 자체(PEPick!, 클래스펫 등)는 건드리지 않는다. 이 사이트는 소개만 한다.
- 로그인, 관리자 화면, 데이터베이스 없음. 정적 사이트 그대로.
- 다크 모드 없음 (낮의 서재 한 가지 모습으로 간다 — 내 판단).

실패로 보는 것 (기술적으로 돌아가도 실패)
- **AI가 만든 티**: 빈 공간이 남는 카드, 칸마다 같은 둥근 모서리·그림자, 화면마다 긴 설명 문장, 이모지 장식, 01/02/03 번호 장식 (근쌤 지적).
- 한 화면에 목록·숫자·설명이 빽빽하게 몰림.
- 확인되지 않은 숫자(강의 횟수, 수강생 수 등)를 지어서 넣음.
- 기존 앱 상세 페이지 7개로 가는 링크가 깨짐.

## 3. 디자인 언어 (시안 그대로)

- **분위기**: 햇살 드는 낮의 서재. 밝은 바탕(#F6F8FC 계열), 남색 글씨(#0E1E46), 오른쪽 위에서 들어오는 노을빛 번짐(#F2A65A, 은은하게).
- **포인트**: BMW M 세 줄(하늘색 #5CB4E6 · 남색 #1E3F95 · 빨강 #E2261C)을 **작은 띠**로만 쓴다 (제목 아래 44px 정도). 근쌤이 BMW를 좋아해서 들어간 요소. 크게 쓰지 않는다.
- **글꼴**: 제목 Gothic A1 900, 본문 IBM Plex Sans KR, 작은 표시·숫자 IBM Plex Mono (Google Fonts).
- **나누는 방식**: 카드 대신 **얇은 선(hairline) 한 줄**로 나눈 목록. 진하게 칠한 상자는 꼭 강조할 것 하나에만.
- **글 양**: 화면마다 큰 문장 하나 + 작은 글 한 줄 이하.
- **움직임 (내 판단)**: 은은하게만. 처음 열 때 M 세 줄이 왼쪽에서 그어지고, 노을빛이 아주 천천히 숨 쉬듯 움직인다. 섹션은 보이는 상태에서 살짝 떠오르는 정도(처음부터 안 보이게 숨기지 않는다). `prefers-reduced-motion`이면 전부 끈다.

## 4. 페이지 구성

### 메인 `index.html` — 위에서 아래로 한 화면씩

| 순서 | 화면 | 들어가는 것 | 시안 |
|---|---|---|---|
| 1 | 첫 화면 | 손 흔드는 근쌤(동그란 틀) · "근쌤 · 초등 체육 교사, 바이브 코더" · **읽고, 생각하고, 쓰거나 만듭니다.** · M 세 줄 · 아래 메뉴(만든 것 · 쓴 글 · 강의 · 연락) | 있음 |
| 2 | 만든 것 | "체육 시간에 쓰는 앱을 만듭니다." · 앱 목록(로고 + 이름 + 짧은 분류) 4개 · "7개 모두 보기" | 있음 |
| 3 | 쓴 글 | "읽고 생각한 것을 씁니다." · 브런치 글 3편(제목만) · 브런치로 가기 | 없음 — 2번과 같은 목록 형식으로 |
| 4 | 강의 | 강의 주제 한 줄 + 대표 강의 2~3개(제목만) | 없음 — 같은 형식, 내용은 아래 7번 질문 |
| 5 | 함께 일하기 | "연수와 협업, 편하게 연락 주세요." · "AI 교사 연수 · 체육 수업 앱 · 글" · 연락 버튼 · 브런치 · 유튜브 · 인스타그램 | 있음 |

- 휴대폰: 화면 하나가 대략 한 화면 높이. 노트북: 가운데 폭 제한(대략 1100px) 안에서 왼쪽 정렬, 앱 목록은 두 줄로 펼쳐도 됨 (내 판단 — 시안은 휴대폰만 그렸음).
- "7개 모두 보기"는 같은 페이지에서 목록을 펼친다 (내 판단).
- 맨 위 메뉴 "메뉴"는 휴대폰에서 같은 4개 메뉴로 펼쳐지는 패널.

### 앱 상세 페이지 7개 (`pepick.html` 등)

내용과 스크린샷은 그대로 두고 **겉모습만** 새 디자인 언어로 바꾼다: 같은 글꼴·색·선 나눔, 맨 위 "← 근쌤" 돌아가기, M 세 줄. 지금 쓰는 Tailwind CDN과 `apple-*` 색 설정은 걷어낸다.

## 5. 만드는 방법 (내 판단)

- 지금처럼 **HTML + CSS + 바닐라 JS**, 빌드 없이. 기존 사이트가 이 방식이고 7개 상세 페이지도 같아서 React로 옮길 이유가 없다.
- CSS는 역할별로 나눈다: `css/tokens.css`(색·글꼴·간격), `css/base.css`, `css/home.css`, `css/detail.css`. 지금 `css/style.css`(1,019줄)는 새 파일들로 대체한 뒤 지운다(삭제 전 근쌤 확인).
- 이미지: 근쌤 캐릭터 `geunssam-video-studio/ai7030-intro/public/char/hires-wave.png`를 `images/profile/geunssam-wave.png`로 복사. 앱 로고·스크린샷은 지금 `images/` 그대로.
- 개편은 새 브랜치 `redesign/seojae`에서. 끝나면 근쌤 확인 뒤 main에 합친다.
